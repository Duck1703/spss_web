# exercises/ — Bài tập

- **Trạng thái:** trống — bài tập sẽ được tạo cùng module tương ứng.
- **Đặt tên:** `Mxx-<slug>.md` (vd `M03-nhap-csv-loi.md`). Bài tập trong `workbook.md` của từng module có thể trỏ tới file ở đây khi cần tách riêng.
- **Quy tắc:** mỗi bài tập ghi rõ đầu vào cần (dataset, version, tiên quyết); bài tập "tự làm không nhìn hướng dẫn" phải là biến thể khác bài mẫu (Blueprint §6 mục 10).
- Đáp án đặt tại `solutions/` cùng tên file — chỉ tạo khi expected đã tái tính.
