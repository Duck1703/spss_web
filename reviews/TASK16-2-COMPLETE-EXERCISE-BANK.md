## 4. Implementation (canonical → generated)

All pages are **generated by `sync-content.mjs`** (new `syncExerciseBank()`) from `exercise-inventory.json` — single source of truth, consistent with the existing canonical-content architecture:

- `/kho-bai-tap/` — hub: search box + 4 filters (source / skill / tier / status), grouped Bài 1 (43) / Bài 2 (15) / Phụ (2), live count, per-card status badge.
- `/kho-bai-tap/{id}/` — 60 detail pages: ID + PDF ref + page · requirement · artifact · dataset (local path, not downloadable) · vars · skills · prereqs · step-by-step `ops` · progressive `<details>` hints · answer-entry inputs (per-field `answerSpec` or textarea) · done button · answer-key link or `ANSWER_NOT_VERIFIED` flag · lesson links (`day` field, incl. `d10+d14`, `d12+d13`) · related exercises.
- `public/js/exercise-bank.js` — filter/search/status (read-only on localStorage; writes stay in `progress.js`).
- `progress.js` — `kho-bai-tap` added to `lastPage` route regex only; no schema change, no key resets.
- `astro.config.mjs` — sidebar "Kho bài tập (58 câu)" + script tag.
- Day lessons get generated **A — Bắt buộc / B — Luyện thêm / C — Nâng cao** mini-cards linking to detail pages (P2-TH3 `day` corrected `d12`→`d12+d13` in inventory so capstone shows on both days).
- CSS: exb/exd components + `[hidden]` override fix (`.exb-card{display:flex}` was beating the `hidden` attribute — found via browser test).
- Also fixed pre-existing cosmetic bug: `{/* */}` banner rendered literally on all `.md` pages → format-aware comment in `write()`.
